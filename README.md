# Awesome HumHub

A curated list of awesome resources for [HumHub](https://www.humhub.com).

## Official resources

* [Documentation](https://docs.humhub.org/docs/about/humhub)
* [Release notes](https://docs.humhub.org/docs/about/releasenotes/release_notes)
* [Module marketplace](https://marketplace.humhub.com/)
* [Install & Administration documentation](https://docs.humhub.org/docs/admin/introduction)
* [Developer documentation](https://docs.humhub.org/docs/develop/overview)
* [humhub on GitHub](https://github.com/humhub): the source code of HumHub, its official modules and its Docker images

## Themes

This section only lists themes **not available** on the [marketplace](https://marketplace.humhub.com/).

* [FlatHub V2](https://github.com/WebCrew/HumHub_Flathub_Updated) by [@felixhahnweilheim](https://github.com/felixhahnweilheim) and [@WebCrew](https://github.com/WebCrew)
* [Orange Theme](https://github.com/felixhahnweilheim/humhub-themes-orange) by [@felixhahnweilheim](https://github.com/felixhahnweilheim)

## Community

* [Community forum](https://community.humhub.com/): questions, help and announcements, with the HumHub team and other administrators
* [Translations](https://translate.humhub.org/): translate HumHub and its modules into your language
* [humhub-contrib on GitHub](https://github.com/humhub-contrib): modules by and for the HumHub community

## Modules

### Other marketplaces

Module stores besides the official [marketplace](https://marketplace.humhub.com/).

* [CUZY modules](https://www.cuzy.app/modules) by [@cuzy-app](https://github.com/cuzy-app): **free and paid**, most of them also on the official marketplace
* [Green Meteor modules](https://greenmeteor.net/modules) by Green Meteor: **free and paid**, some of them also on the official marketplace

### Modules outside the marketplace

This section only lists modules **not available** on the [marketplace](https://marketplace.humhub.com/).

* [Email Log](https://github.com/cuzy-app/email-log) by [@cuzy-app](https://github.com/cuzy-app): logs every email HumHub sends (recipient, subject, content, status, error), with a searchable administration list, failure alerts and auto-purge, HumHub 1.19+ (**free**, AGPL-3.0)
* [Module Editor](https://github.com/felixhahnweilheim/humhub-module-editor) by [@felixhahnweilheim](https://github.com/felixhahnweilheim): create and edit modules from the administration UI (**free**)
* [Recent Spaces](https://github.com/Basster/humhub-modules-recent-spaces) by [@Basster](https://github.com/Basster): dashboard panel with the latest spaces created (**free**)
* [Developer Tools](https://github.com/humhub-contrib/devtools) by [humhub-contrib](https://github.com/humhub-contrib): utilities for module developers (**free**)
* [humhub-contrib](https://github.com/humhub-contrib): more modules by and for the HumHub community (**free**)

## Hosting and deployment

* [HumHub Professional Edition and SaaS](https://www.humhub.com/pricing/): the official offer of HumHub GmbH
* [Official Docker images](https://github.com/humhub/docker)
* [Cloudron package](https://docs.cloudron.io/packages/humhub/)

## Developer tools

* [module-coding-standards](https://github.com/humhub/module-coding-standards): the shared Rector, PHP CS Fixer and PHPStan configurations and GitHub workflows of HumHub modules
* [humhub-suneditor](https://github.com/cuzy-app/humhub-suneditor): a SunEditor rich-text field for module forms, with inline uploads (a library, not a module)
